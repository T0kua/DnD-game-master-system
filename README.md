# D&D game master system 
tools for Dungeon master; includes virtual table tool, web interface for players, wiki

Я не нашел на гитхабе чего-то более похожего под мои нужды, и тем более open source, так что я воспользовался достижением последних витков эволюции "вайбкодингом"
почти весь код написан нейросетью, но патчи и коррекции выполнялись вручную

> [!WARNING]
> проект сырой, вы можете встретить кнопку которая ничего не делает, ссылку в никуда, ещё что-нибудь, я над этим работаю, прост времени мало   
> НО я на 100% уверен что если не быть юзверем, то у вас ни один моб не сдвинется с того места на которое вы его поставили, ни один персонаж не испортится из-за ошибки сохранения

Некоторые возможности приложения:
- **Окно мастера** (tkinter): сцены, карта, токены, бестиарий, листы персонажей,
  статблоки, броски, бой, заметки, музыка, трансляция на второй экран, своя википедия, плагин отслеживания времени в игре.
- **Сайт игроков** (Flask): у каждого игрока — личная ссылка на свой лист
  персонажа (предметы, способности, ресурсы).

## Запуск

```bash
python app.py
```

Перед стартом откроется **выбор кампании** (создать / открыть / удалить).
Каждая кампания хранится отдельно в `data/campaigns/<имя>.json`.

Можно пропустить диалог:

```bash
python app.py --campaign "Моя кампания"
```
